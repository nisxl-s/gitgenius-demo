# GitGenius demo

This repository contains a small Go program that prints a version, an SLTC greeting, and a message naming the development branch.

## Run the demo

Install [Go](https://go.dev/dl/), then run this command from the repository root:

```sh
go run main.go
```

Expected output:

```text
Version 3.0.0
Hello! SLTC
This is from the development branch
```
